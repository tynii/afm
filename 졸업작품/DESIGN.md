# DESIGN — 위시 모아보기 v1

> 콘셉트: **My wish scrapbook** — 흩어진 위시를 카테고리별 색 대지에 한 장씩 붙여 스크랩북처럼 모은다.
> 참고: 스크랩북·우표 컬렉션·파스텔 폴더처럼 "모으는" 느낌의 레퍼런스(테이프 라벨, 컬러 카드 + 폰 목업)
> 위시 한 장 = 스크랩 카드. 여러 장을 묶는 **컬렉션은 다음 버전에서 별도의 아날로그 물건 모양**으로 만든다(아래 7절).

## 1. 톤앤매너

- **모으는 재미.** 위시는 인화한 사진 한 장을 테이프로 붙인 스크랩 카드로 보인다. 사진은 살짝 기울여 손으로 붙인 느낌을 준다.
- **색은 카테고리가 가진다.** 바탕은 종이 같은 웜 오프화이트, 글자는 잉크색. 화면의 색은 카테고리 6가지 파스텔과 위시 사진에서 나온다.
- **세리프 이탤릭은 포인트로만.** 영문 라벨(My wish scrapbook, Culture, Note 등)에만 쓰고, 본문·버튼은 산세리프.
- **모바일 퍼스트, 한 손 조작.** 주요 버튼은 손가락 높이(44px 이상), 담기 버튼은 화면 아래 가운데.
- **문구는 짧은 존댓말(해요체).** 예: "제목을 입력해 주세요." · "아직 담은 위시가 없어요."
- 이모지는 쓰지 않는다.

## 4. 간격·모서리

- 화면 좌우 여백 16px, 최대 폭 448px(`max-w-md`) 가운데 정렬
- 카드 그리드: 2열, 가로 12px · 세로 16px 간격
- 폼 항목 사이 24px, 라벨과 입력창 사이 8px
- 모서리: 스크랩 카드 16px(상세 26px) · 인화지 5px(상세 8px) · 입력창·버튼·링크 카드 12~16px · 칩·담기 버튼 완전 둥글게

## 5. 컴포넌트

| 컴포넌트 | 스타일 |
|---|---|
| **스크랩 카드** (목록) | 카테고리 색 대지 위에 흰 인화지(테두리 6px)에 뽑은 정사각형 사진. 사진은 짝수/홀수에 따라 -1.5°/+1.2° 기울이고, 위 가운데에 반투명 **테이프**(-4°). 아래에 영문 라벨 + 제목 2줄. 이미지가 없거나 깨지면 **빈 인화지**가 붙어 있는 모습 |
| **스크랩 카드** (상세) | 같은 구조를 크게. 사진은 **잘리지 않게 전체** 표시, 제목 22px |
| 필터 칩 (목록) | 높이 36px 알약. 기본: 흰 70% 바탕 + 선 테두리 + 카테고리 색 점. 선택: 그 카테고리의 앞주머니 색으로 채움(전체는 잉크). 가로 스크롤, 오른쪽 끝은 종이색으로 흐리게 |
| 카테고리 선택 (폼) | 3칸×2줄, 높이 44px, 12px 둥글게. 색 규칙은 필터 칩과 같음 |
| 주 버튼 | 높이 48px, 잉크 바탕, 흰 글자, 전체 너비 |
| 보조 버튼 | 높이 48px, 흰 바탕 + 선 테두리. 삭제는 글자만 빨강 |
| 입력창 | 높이 48px, 흰 바탕, 선 테두리. 포커스 시 테두리 진해지고 3px 옅은 링 |
| 링크 카드 (상세) | 높이 56px, 흰 바탕, 왼쪽 사이트 주소(돌색) · 오른쪽 "링크 열기 ↗" |
| 메모 쪽지 (상세) | 흰 카드 위 가운데에 반투명 **테이프** 한 조각(-3°), 영문 "Note" 라벨 |
| 상단 바 | 높이 56px, 고정, 종이색 90% + 블러, 둥근 뒤로가기 버튼. 브라우저 뒤로가기와 같게 동작하고 목록의 필터·스크롤 위치를 유지 |
| 담기 버튼 | 화면 아래 가운데 고정, 높이 48px 잉크 알약, `+` 아이콘, 아래로 퍼지는 부드러운 그림자 |
| 로딩 | 카드 모양 스켈레톤 4개가 깜빡임, 나머지는 "불러오는 중…" |

- 1920×1080, 종이 바탕. 위 가운데 메인 제목: **"My wish *scrapbook*"**(Instrument Serif 168px, "scrapbook"만 이탤릭) + `v1` 배지 → 그 아래 "**위시 모아보기** : 흩어진 나의 위시를 한 곳에 차곡차곡"(Pretendard 40px)

## 7. 다음 버전: 컬렉션 디자인 방향 (아직 만들지 않음)

컬렉션("도쿄 여행"처럼 위시 여러 개를 묶은 것)은 폴더 아이콘이 아니라 **손에 잡히는 아날로그 문구류** 모양으로 만든다.

- **스케치북:** 크라프트지 표지 + 왼쪽 스프링 + 끈 리본. 컬렉션 목록의 표지로 쓴다.
- **엽서·봉투:** 봉투 안에 위시 카드가 몇 장 꽂혀 삐져나온 모습.
- **파일 포켓:** 크라프트 파일 + 색 탭 + 클립으로 꽂은 이름표, 도서관 대출 카드가 꽂힌 노란 포켓처럼.
- 색·종이 바탕·세리프 라벨·테이프는 지금 규칙을 그대로 쓴다.
