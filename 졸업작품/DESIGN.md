# DESIGN — 위시 모아보기 v1

> 참고: [shadcn/ui](https://ui.shadcn.com/) · [component.gallery](https://component.gallery/) — 라이브러리는 설치하지 않고 스타일만 Tailwind로 옮겼다.

## 1. 톤앤매너

- **위시 이미지가 주인공.** UI는 흰 바탕과 회색 선으로 물러나 있고, 색은 사진에서만 나온다.
- **모바일 퍼스트, 한 손 조작.** 주요 버튼은 손가락 높이(44px 이상), 담기 버튼은 화면 아래 가운데.
- **장식 최소화.** 그림자는 담기 버튼에만 아주 약하게. 이모지·일러스트·그라데이션은 쓰지 않는다.
- **문구는 짧은 존댓말(해요체).** 예: "제목을 입력해 주세요." · "아직 담은 위시가 없어요."

## 2. 컬러

shadcn/ui 기본 테마(Neutral)의 값과 같은 Tailwind `neutral` 팔레트를 쓴다.

| 역할 | 값 | Tailwind | 쓰는 곳 |
|---|---|---|---|
| 배경 | `#FFFFFF` | `white` | 페이지, 입력창 |
| 글자 | `#0A0A0A` | `neutral-950` | 제목, 본문 |
| 주 버튼·선택된 칩 | `#171717` | `neutral-900` | 저장, 위시 담기, 선택된 필터 |
| 보조 글자 | `#737373` | `neutral-500` | 안내 문구, 메모 라벨 |
| 흐린 글자 | `#A3A3A3` | `neutral-400` | placeholder, "선택" 표시, 개수 |
| 테두리 | `#E5E5E5` | `neutral-200` | 입력창, 칩, 보조 버튼, 구분선 |
| 옅은 면 | `#F5F5F5` | `neutral-100` | 이미지 없는 카드, 로딩 스켈레톤, hover |
| 더 옅은 면 | `#FAFAFA` | `neutral-50` | 상세 이미지 여백 |
| 위험 | `#DC2626` | `red-600` | 삭제 버튼, 오류 문구 |

## 3. 폰트

- **Pretendard Variable** (CDN: jsDelivr `orioncactus/pretendard@v1.3.9`, dynamic subset), 없으면 시스템 폰트
- 한글 줄바꿈: `word-break: keep-all` (단어 중간에서 끊지 않음)

| 용도 | 크기 / 굵기 |
|---|---|
| 목록 큰 제목 | 24px / Bold, 자간 좁게 |
| 상세 제목 | 20px / Semibold |
| 상단 바 제목 | 16px / Semibold |
| 입력창 | 16px (iOS 자동 확대 방지) |
| 카드 제목·버튼·라벨 | 14px / Medium |
| 칩 | 13px / Medium |
| 배지 | 12px / Medium |

## 4. 간격·모서리

- 화면 좌우 여백 16px, 최대 폭 448px(`max-w-md`) 가운데 정렬
- 카드 그리드: 2열, 가로 12px · 세로 24px 간격
- 폼 항목 사이 24px, 라벨과 입력창 사이 8px
- 모서리: 카드·큰 이미지 12px · 입력창·버튼 8px · 배지 6px · 칩·담기 버튼 완전 둥글게

## 5. 컴포넌트

| 컴포넌트 | 스타일 |
|---|---|
| 위시 카드 | 정사각형 이미지(12px 둥글게, 안쪽 5% 검정 테두리) + 아래 제목 2줄. 테두리 상자 없음. 이미지가 없거나 깨지면 빈 회색 칸 |
| 필터 칩 (목록) | 높이 32px, 둥근 알약 모양. 기본: 흰 바탕+회색 테두리, 선택: 검정 바탕+흰 글자. 가로 스크롤(스크롤바 숨김), 오른쪽 끝을 흰색으로 흐리게 해서 더 있다는 걸 알림 |
| 카테고리 선택 (폼) | 3칸×2줄 그리드, 높이 40px, 8px 둥글게. 색 규칙은 필터 칩과 같음 (shadcn ToggleGroup 모양) |
| 주 버튼 | 높이 44px, 검정 바탕, 흰 글자, 전체 너비 |
| 보조 버튼 | 높이 44px, 흰 바탕+회색 테두리. 삭제는 글자만 빨강 |
| 입력창 | 높이 44px, 회색 테두리. 포커스 시 테두리 진해지고 3px 옅은 링 |
| 상단 바 | 높이 56px, 화면 위에 고정, 반투명 흰 배경+블러, 왼쪽 뒤로가기 아이콘. 뒤로가기는 브라우저 뒤로가기와 같게 동작하고, 목록의 필터·스크롤 위치를 유지 |
| 담기 버튼 | 화면 아래 가운데 고정, 높이 48px 알약 모양, `+` 아이콘 + "위시 담기", 아주 약한 그림자 |
| 상세 이미지 | 정사각형 틀 안에 **잘리지 않게 전체** 표시(`object-contain`), 남는 공간은 아주 옅은 회색 `#FAFAFA` |
| 링크 버튼(상세) | 높이 48px, 왼쪽 사이트 주소(회색) · 오른쪽 "링크 열기 ↗" |
| 카테고리 배지(상세) | 높이 24px, 회색 테두리, 작은 글자 |
| 로딩 | 목록은 회색 스켈레톤 카드 4개가 깜빡임, 나머지는 "불러오는 중…" |
| 아이콘 | lucide 모양을 옮긴 선 아이콘(두께 2) — 뒤로, 더하기, 외부 링크 3개만 |
