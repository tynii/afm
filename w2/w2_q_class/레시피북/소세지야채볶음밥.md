# 소세지 야채볶음밥 (15분)

![소세지 야채볶음밥 썸네일](images/소세지야채볶음밥-썸네일.png)

냉장고 속 자투리 야채와 소세지로 뚝딱 만드는 든든한 볶음밥이에요.

## 재료 (1인분)
- 밥 1공기 (찬밥이면 더 좋아요)
- 소세지 2개 (어슷 썰기)
- 양파 1/4개 (다지기)
- 당근 1/6개 (다지기)
- 대파 1/4대 (송송 썰기)
- 케첩 2큰술
- 간장 1작은술
- 소금, 후추 약간
- 식용유

## 만드는 법

1. **재료 손질 (3분)** — 소세지는 어슷하게 썰고, 양파와 당근은 잘게 다져둡니다.

2. **소세지 굽기 (3분)** — 팬에 식용유를 두르고 소세지를 넣어 겉면이 노릇해질 때까지 중불에서 볶습니다.

3. **야채 볶기 (3분)** — 양파와 당근을 넣고 숨이 죽을 때까지 함께 볶아줍니다.

4. **밥 볶기 (4분)** — 밥을 넣고 강불에서 골고루 섞어가며 볶다가 케첩과 간장을 넣어 색과 간을 맞춥니다.

5. **마무리 (2분)** — 대파를 넣고 소금, 후추로 간을 맞춘 뒤 불을 끄고 그릇에 담아냅니다.

## 팁
- 케첩을 먼저 볶아 신맛을 날리면 감칠맛이 더 좋아져요.
- 계란프라이를 올리면 아이들도 좋아하는 한 끼가 됩니다.
- 냉동 완두콩이나 옥수수를 추가해도 잘 어울려요.
