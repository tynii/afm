# 아보카도 계란 토스트 (15분)

![아보카도 계란 토스트 썸네일](images/아보카도계란토스트-썸네일.png)

부드러운 아보카도와 반숙 계란이 어우러진 든든하고 건강한 브런치 토스트예요.

## 재료 (1인분)
- 식빵 2장
- 아보카도 1/2개
- 계란 1개
- 레몬즙 1작은술
- 소금, 후추 약간
- 올리브유 약간
- 페퍼론치노 또는 크러시드 레드페퍼 (선택)

## 만드는 법

1. **식빵 굽기 (3분)** — 토스터나 마른 팬에 식빵을 노릇하게 구워둡니다.

2. **아보카도 으깨기 (3분)** — 아보카도를 반으로 갈라 씨를 제거하고 볼에 담아 포크로 으깬 뒤 레몬즙, 소금, 후추로 간을 합니다.

3. **계란 반숙 만들기 (5분)** — 팬에 올리브유를 살짝 두르고 계란을 깨 넣어 반숙 프라이나 수란으로 익힙니다.

4. **토스트에 올리기 (2분)** — 구운 식빵 위에 으깬 아보카도를 골고루 펴 바릅니다.

5. **마무리 (2분)** — 아보카도 위에 반숙 계란을 올리고 소금, 후추, 페퍼론치노를 뿌려 완성합니다.

## 팁
- 아보카도가 덜 익었다면 전자레인지에 10초 정도 살짝 데우면 더 부드러워져요.
- 훈제연어나 베이컨을 곁들이면 더 근사한 브런치가 됩니다.
- 레몬즙은 아보카도의 갈변도 막아줘요.
