# DEV — 위시 모아보기 v1 개발 계획

> 기준: [MISSION.md](MISSION.md) · 핵심 기능 = **위시 담기 → 카드로 모아보기** · 성공 기준 = 폰에서 링크 10개 + 제목만 2개, 12개가 카드로 보이고 카테고리 필터가 동작

## 1. 화면 (2개, `index.html` 하나에 해시 라우팅)

| 화면 | 역할 |
|---|---|
| 목록 `#/` | 위: 카테고리 버튼(전체·쇼핑·영화/방송·책·카페·여행지·전시) / 아래: 위시 카드(이미지·제목, 누르면 원래 링크) / `+` 버튼 → 담기 |
| 담기 `#/add` | 링크 칸 + [불러오기] → 제목·이미지 주소 칸(자동으로 채워지고 수정 가능) → 카테고리 1개 탭 → [저장] |

## 2. 데이터 (Supabase 테이블 1개)

`wishes`: `id` · `title`(필수) · `url`(선택) · `image_url`(선택) · `category`(6개 중 하나, 텍스트) · `created_at`
카테고리는 별도 테이블 없이 텍스트 칸과 고정 버튼 6개로 처리한다.

## 3. 기술 (6주차 구성 그대로, 새 라이브러리 없음)

`index.html`(React CDN + Tailwind) · `server.js`(Express) · Supabase Postgres(`pg`, `dotenv`) · Vercel 배포

## 4~5. 개발 순서와 단계별 작동 결과

| 단계 | 만들 것 | 끝나면 작동하는 것 / 확인 방법 |
|---|---|---|
| 0 | 폴더 준비, `npm install express pg dotenv`, server.js가 index.html 보여주기 (포트 **3001**) | `npm start` → `localhost:3001`에 빈 화면이 뜬다 |
| 1 | 제목만 담기 + 카드 목록 (`POST`·`GET /api/wishes`, DB 연결) | 2개 담고 새로고침해도 남아 있다 + Supabase Table Editor에서 행이 보인다 |
| 2 | 담을 때 카테고리 선택 + 목록 필터 | 카테고리별로 1개씩 담고 버튼을 누르면 그 종류만 보인다 |
| 3 | 링크·이미지 주소 **직접 입력** | 쿠팡 링크와 이미지 주소를 손으로 넣어 저장 → 이미지 카드가 보이고, 누르면 링크가 열린다 |
| 4 | **자동 추출** `GET /api/preview?url=` (서버가 og:title·og:image를 읽음, 5초 넘으면 중단) | 무신사 링크는 칸이 자동으로 채워진다. 쿠팡 링크는 "직접 입력해줘" 안내가 나오고 3단계 흐름으로 저장된다 |
| 5 | 폰 화면 다듬기 + Vercel 배포 (**배포 전에 허락 받기**) | 폰에서 성공 기준 12개를 통과한다. 배포 서버에서도 자동 추출이 되는지 다시 확인한다 |
| 6 (선택) | 컬렉션: `collection` 텍스트 칸 + 필터 버튼 한 줄 | 5단계를 통과한 뒤에만 시작한다 |

원칙: 자동 추출은 입력 칸을 미리 채워 주는 보조 기능이다. 4단계가 막혀도 3단계까지만으로 v1 성공 기준을 통과할 수 있다.

## 6. 위험 요소와 대비책

| 위험 | 근거 | 대비책 |
|---|---|---|
| 자동 추출 실패 | 2026-10-12 Node fetch 테스트 결과. 성공: 무신사·29CM·오늘의집·교보·예스24·티빙·네이버 플레이스. 실패: 쿠팡(403)·스마트스토어(로그인 페이지)·넷플릭스·인스타(og 태그 없음) | 직접 입력(3단계)을 먼저 만든다. 실패하면 안내 문구를 띄우고 입력 칸은 그대로 수정할 수 있게 둔다 |
| 배포 서버에서 더 많이 막힘 | Vercel은 집 PC와 IP가 다르다 (아직 확인 안 함) | 5단계에서 다시 측정한다. 막히는 사이트가 늘어도 직접 입력으로 저장한다 |
| 제목에 `&amp;` 같은 특수문자가 섞임 | 무신사 og:title 결과 | 서버에서 특수문자를 변환한 뒤 응답한다 |
| 이미지가 깨짐 | 다른 사이트 이미지 직접 표시가 막힐 수 있다 | 이미지가 안 뜨면 카테고리 이모지 카드로 대신 보여준다 |
| 배포 후 DB 연결 실패 | 6주차와 같은 구조 | Vercel 환경변수에 `DATABASE_URL`을 등록한다 |
| 포트 충돌 (`EADDRINUSE`) | 2026-10-12 확인: 3000번은 6주차 가구 쇼핑몰 서버가 사용 중 | 이 프로젝트는 3001번을 쓴다 (`process.env.PORT \|\| 3001`) |
| 범위가 커짐 (컬렉션·수정·삭제) | MISSION.md의 v1 제외 목록 | 5단계를 통과하기 전에는 손대지 않는다 |
